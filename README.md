# Trama — client contact

This is the public contact channel for **TramaLocalPrototype**, a local video-authoring prototype with a Wikimedia Commons media client.

## Contact the operator

[Open a contact request](https://github.com/samaeljvoolt-png/trama-contact/issues/new?template=contact.yml) for questions about this client, unexpected requests, resource attribution, or license metadata. Replies take place in the GitHub issue. Messages are public; do not include passwords, API keys, or private files.

[View existing requests](https://github.com/samaeljvoolt-png/trama-contact/issues).

## Client identification

- Client: `TramaLocalPrototype/0.2`
- Contact URL: https://github.com/samaeljvoolt-png/trama-contact
- Purpose: search Commons video metadata and import individually selected resources into an authenticated local project.
- The prototype records the source and license metadata of imported files. A resource still requires review before publication.
- Requests identify this contact URL in the HTTP User-Agent header.

This repository contains contact information only. It does not contain the Trama application source, credentials, private projects, or media. Trama is an experimental prototype; this page does not announce a public commercial service or an affiliation with Wikimedia.
